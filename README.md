# GOWR Custom Cheats — PS4

Custom GoldHEN cheat menu project for **God of War Ragnarök** on PlayStation 4.

Press SHARE to open the cheats, you can activate cheats meanwhile youre playing. 

## Compatibility

- Platform: PlayStation 4
- Game: God of War Ragnarök
- Title ID: CUSA34384
- Game version: 06.00
- Environment: GoldHEN

## Features

- Custom cheat names in Spanish.
- 10 cheats based on the existing GoldHEN trainer.
- Infinite Health, Rage, Arrows and Weapon Charge.
- Max XP and Resources.
- Interactive HTML menu preview.
- C-based input and navigation prototype.
- Planned L1 + Circle menu shortcut.

## Installation

1. Download or clone this repository.
2. Run `GENERAR_WINDOWS.bat` on Windows with Python 3 installed.
3. Find the generated `CUSA34384_06.00.shn` file in the `SALIDA` folder.
4. Back up any existing cheat files.
5. Transfer the file to `/user/data/GoldHEN/cheats/shn/` using FTP.
6. Launch God of War Ragnarök.
7. Hold SHARE to open the GoldHEN cheat menu.
8. Select cheats and toggle them using X.

## Development Status

**Experimental — Work in progress.**

The GoldHEN cheat file generator is implemented, but the project has not been tested on a physical PS4.

The custom graphical overlay and L1 + Circle shortcut are prototypes only. There is currently no installable PS4 `.prx` plugin.
